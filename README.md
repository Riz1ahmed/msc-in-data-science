# MSc Data Science — Arden University

Personal repository for coursework, notes, and projects from my **MSc Data Science** at [Arden University](https://arden.ac.uk/).

The programme sits in the Faculty of Social Sciences and Technology. It runs from mathematical foundations through machine learning, artificial intelligence, cloud computing, and a final research project. Teaching follows a “learn by doing” approach: modules use real datasets, industry tools, and practical assessments that build a portfolio of work.

Official course page: [MSc Data Science | Arden University](https://arden.ac.uk/our-courses/postgraduate/masters/msc-data-science)

## What the course covers

- Gathering, processing, and analysing data for operational and strategic decisions
- Mathematical foundations: linear algebra, calculus, statistics, and probability
- Programming for data science, mainly in Python, with Jupyter notebooks
- Machine learning, artificial intelligence, neural networks, and deep learning
- Big data and cloud computing, including Hadoop
- Data visualisation and communicating findings to technical and non-technical audiences
- Ethical, legal, and professional constraints on data science work

Full-time blended study is one year. Online study is part-time and typically one year or longer. Study options include blended learning in London (Stratford) and Manchester, full-time study in Berlin, and fully online study through Arden’s iLearn platform.

## Modules

The award is 180 credits at Level 7.

| Module | Credits |
| --- | ---: |
| Programming for Data Science | 20 |
| Mathematics for Data Science | 20 |
| Big Data and Cloud Computing | 20 |
| Machine Learning | 20 |
| Artificial Intelligence and Neural Networks | 20 |
| Data Visualisation | 20 |
| Advanced Computing Project | 60 |

The Advanced Computing Project (also described by Arden as the Data Science Research Project) is the final piece of the degree: an independent research, design, and implementation project on a real data science problem, supervised in a chosen area.

## How the course is assessed

Modules are assessed through practical, real-world work. Portfolio submissions include assets built with industry tools during each module. Written work is used to explain methods and communicate results. Formative feedback is given before summative assessment.

## Tools used on the programme

Arden’s course materials include hands-on work with:

- Python, R, Jupyter Notebooks, JupyterLab, Anaconda, Spyder, and PyCharm
- Tableau, Glueviz, and Orange
- TensorFlow
- Cloud platforms including Microsoft Azure, AWS Academy, Oracle Cloud, and Cisco Networking Academy resources

Optional vendor study, available alongside the degree, includes Microsoft Security, Compliance, and Identity Fundamentals (SC-900) and Microsoft Azure Security Technologies (AZ-500).

## Entry requirements (programme)

Arden assesses applications individually. Published standard entry is a 2:2 honours degree (or equivalent) in a numerate subject. Non-standard entry can include at least three years of relevant work experience. Where English is not the first language, the usual requirement is IELTS 6.5 overall, with no component below 6.0, or equivalent previous study in English.

Source: [MSc Data Science programme specification (Arden University, February 2025)](https://cdn.arden.ac.uk/s3fs-public/2025-02/MSc%20Data%20Science%20Programme%20Specification.pdf).
